Backup

Your documents exist only in this browser. Clearing site data or losing this device deletes them, so export a backup now and then.

Export backup One .inkframe.json file with every document, its version history and its images.
Restore from backup Add the documents in a backup file to this browser, or replace everything here with them.

Danger zone

Delete all data Permanently deletes every document and image in this browser. Your theme is kept. Export anything you need first.
