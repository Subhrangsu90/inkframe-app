Product Architecture & Local Sync

Modified moments ago · 438 words · 2 min read · IndexedDB.wal OK

Inkframe is architected from the ground up for instantaneous responsiveness. Unlike typical browser editors that stream keystrokes across WebSockets to cloud clusters, Inkframe treats your local storage device as the immutable source of truth.

import { openDB } from 'idb';

// Zero round-trip persistence pipe
export async function persistDocument(docId, markdownAST) {
  const db = await openDB('inkframe_core', 2);
  const tx = db.transaction('documents', 'readwrite');
  
  await tx.store.put({
    id: docId,
    content: markdownAST,
    savedAt: performance.now(),
    offlineVerified: true
  });
  return tx.done;
}
